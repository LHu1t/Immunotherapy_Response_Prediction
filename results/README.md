LUAD = Lung Adenocarcinoma  
LUSC = Lung Squamous Cell Carcinoma

APM = Antigen Presentation Machinery score  
TIS = T-cell Inflamed Signature score

Each NPZ file contains model predictions and ground-truth gene expression
values for a held-out test fold.

Stored arrays:

- preds_z: predicted gene expression values generated by the model
  (z-score normalized).

- targets_z: true gene expression values for the corresponding samples
  (z-score normalized).

- targets_raw: true gene expression values in their original processed
  scale.

- gene_cols: gene names corresponding to matrix columns.

These files are used to compute downstream analyses including:

- T-cell Inflamed Signature (TIS) scores
- Antigen Presentation Machinery (APM) scores
- ROC curves for top-quartile TIS/APM classification
- Pearson correlation analyses

TIS and APM scores are not stored directly in the NPZ files but are
calculated from the gene-level predictions using the corresponding
signature gene sets.
