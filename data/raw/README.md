# Raw Data

Raw gene expression and clinical data were obtained from the
Genomic Data Commons (GDC).

Gene expression data were downloaded as individual sample-level files.

These files are not redistributed in this repository because they are
publicly available from the original source and substantially increase
repository size. However, please see sample files provided in the folder:

'''data/raw/example_expression_files/'''

The preprocessing pipeline used to generate the processed dataset is
provided in the folder:

'''src/preprocessing/prepare_expression_data/'''

The resulting processed dataset is included as:

'''data/processed/expression_clinical_processed.csv'''
